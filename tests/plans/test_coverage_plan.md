# План тестового покрытия — DJILab

## Сущности приложения

| Сущность | Критичные сценарии | Приоритет | Тип теста |
|----------|-------------------|-----------|-----------|
| **User/Profile** | Регистрация, авторизация, права доступа | Высокий | Unit + Integration |
| **Service** | Создание, фильтрация, поиск | Средний | Integration |
| **Order** | Создание, изменение статуса, расчёт суммы | Высокий | Integration |
| **OrderItem** | Добавление/удаление из заказа | Средний | Integration |

## Стратегия тестирования

### 1. Что тестируем в первую очередь (Высокий приоритет)
- [✅] Регистрация: валидация пароля, дубликаты
- [✅] Авторизация: успешный вход, ошибки
- [✅] Создание заказа: черновик, расчёт total
- [ ] Права доступа: is_staff ограничивает данные

### 2. Какие тесты — Unit, какие — Integration

#### Unit-тесты (быстрые, изолированные):
- Валидация пароля (граничные значения: 7/8/32/33 символа)
- Фильтрация по цене (Decimal сравнения)
- Утилиты: генерация ключей, форматирование

#### Integration-тесты (с БД):
- Регистрация → создание User + UserProfile
- Авторизация → сессия + метрики Prometheus
- Добавление в заказ → создание Order + OrderItem + пересчёт total
